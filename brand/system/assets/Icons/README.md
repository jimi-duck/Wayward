# Icons

Thirteen line icons on a 24px grid: 1.75 stroke, square caps, miter joins, angles in multiples of 45°. The files are drawn in `edge` #3E8798 so they read on light and dark grounds. In code use the mask classes `ab-i ab-i--<name>`, which take `color`.

weapons, defence, ship, hull, krail, overcharge, chain, capital, score, torpedo, mine, alert, all-stop.
