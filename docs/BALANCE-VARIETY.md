# Variety report

Generated by `npm run pilot:variety`: 60 eight-region journeys walked over the chart
(no flying), every sortie read as the world would build it. A signature is
objective, expanse, features and holder; a journey is "varied" when its
active (non-breather) systems do not repeat one.

| Measure | Value |
|---|---|
| Systems walked | 4560 (22% breathers) |
| Distinct signatures in the first 12 active systems | 12.0 of 12 |
| Distinct signatures over a whole journey, per active system | 99% |
| Neighbouring active systems with the same objective, expanse and features | 0% |
| Windows of 3 active systems repeating an objective and expanse | 10% |
| Active systems that are a plain crossing (no job, no place) | 31% |
| Active systems with at least one feature in the sky | 98% |
| Heavy jobs (destroy, strike, defend, race, survey, sneak, recover) | 15% of systems |
| Longest run of heavy systems in a row (mean, worst of 60) | 1.6, 3 |
