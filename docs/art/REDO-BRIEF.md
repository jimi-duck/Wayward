# Wayward artwork: redo brief (all in one)

*Written for someone who has never seen this project. Everything you need is here or linked below. 29 pictures, each replacing a weaker one.*

## The project
**WAYWARD** is a 3D space-survival roguelite for desktop and phone browsers (TypeScript, Three.js, Vite). You are a fugitive on a stolen, worn yellow-orange ore hauler, the *Wayward*, carrying proof that a regime hid a purge for seventy years. The mood is industrial cyberpunk frontier: old, patched, regulated technology, "used, not dirty".

**Repository: https://github.com/jimi-duck/Wayward** (branch `main`). Read, in this order:
1. [`docs/VISION.md`](https://github.com/jimi-duck/Wayward/blob/main/docs/VISION.md): what the game is.
2. [`docs/ART-SLOTS.md`](https://github.com/jimi-duck/Wayward/blob/main/docs/ART-SLOTS.md): how pictures reach the game, sizes, what is done.
3. [`docs/art/briefs.md`](https://github.com/jimi-duck/Wayward/blob/main/docs/art/briefs.md): the full prompt for every picture in the game (this brief reuses the ones for the pictures below).
4. [`src/art/`](https://github.com/jimi-duck/Wayward/tree/main/src/art): every finished picture, by folder. Open a few (`ships/`, `fleet/`, `jobs/`, `phenomena/`) to see the standard to match.

**Reference pictures for the look** (match these, they are the art direction):
- Title art: https://github.com/jimi-duck/Wayward/blob/main/docs/art/reference/wayward-title-art.jpg
- Menu art: https://github.com/jimi-duck/Wayward/blob/main/docs/art/reference/wayward-menu-art.jpg
- Good examples already made: `src/art/fleet/capital-vance.webp`, `src/art/fleet/wayward-scuffed.webp`, `src/art/jobs/sc_toll.webp`, `src/art/phenomena/well.webp`.

**The look in one paragraph:** cinematic, richly detailed, painterly-realistic sci-fi concept art, dark and muted. Mostly void black, off-white, dust grey and rust brown, with one warm yellow-orange anchor (the Wayward). Signal teal only for screens and information, alert red only for threat, dull gold only for caution, nebula purple only far in the background, no neon pink. One key light with a soft rim light and haze. Glow small and restrained. Never cartoonish. **No text, lettering, numbers, logos or watermarks inside any picture.**

**The Wayward:** a long, low, aerodynamic ore hauler in worn yellow-orange, split side engine pods. It must look like the same ship as in the title art in every picture.

## Check the repository's current pictures first, then match them
The game already has about 280 finished pictures. **Before you draw anything, open the ones that sit next to yours and make the new picture look like they belong with them.** Do not work from this file's words alone.
1. Open the folder for each picture on GitHub (links below). The files are `.webp`; GitHub shows them in the browser.
2. Look at **at least five neighbours** in that folder, and the single closest one to each picture you are about to make.
3. Match what you see: the **palette** (dark and muted, one warm yellow-orange anchor, teal only on screens, red only for danger), the **lighting** (one key light and a rim light, soft haze), the **level of detail and wear**, the **camera and framing**, and how much of the frame the subject fills.
4. Where a picture replaces an existing one, open the old one and keep what works (the ship, the subject, the angle) and fix only what the brief names.
5. If you cannot open the repository, say so before you start and ask for the neighbouring pictures to be attached. Do not guess the style.

Folders: ships [`src/art/ships/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/ships), fleet [`src/art/fleet/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/fleet), jobs [`src/art/jobs/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/jobs), phenomena [`src/art/phenomena/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/phenomena), places [`src/art/places/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/places), regions [`src/art/regions/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/regions), gates [`src/art/gates/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/gates), planets [`src/art/planets/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/planets), debrief [`src/art/debrief/`](https://github.com/jimi-duck/Wayward/tree/main/src/art/debrief), icons [`public/icons/node/`](https://github.com/jimi-duck/Wayward/tree/main/public/icons/node).

**For this brief in particular:** every picture here replaces one that already exists under the same name. Open the old file first and the closest good one (`src/art/fleet/capital-vance.webp`, `src/art/jobs/sc_toll.webp`, `src/art/phenomena/well.webp`).

## What to deliver
- Every picture a **separate PNG**, named exactly as its `Save as` line, for example `jobs__sc_bait.png` (two underscores after the folder name). The names match files already in `src/art/`, so the new ones replace the old.
- One ZIP of all of them. If you cannot make a ZIP, one PDF with one picture per page and the file name in a caption outside the picture.
- Do not change anything else in the repository: no code, no docs.
- Why this is being redone: the old ones are too small (800×450 jobs, 640×480 phenomena), have frame lines baked in, or missed the colour palette. Check each picture against its reference before handing back.

## Read this first
- **One picture per image.** Never a sheet, a board, a grid or "variations".
- **No frame lines, borders, text or lettering inside any picture.**
- **Sharper and larger than last time.** 1536 px wide or more for ships, 1672×940 or more for scenes.
- Hand back **one ZIP** of PNGs named as each `Save as` line says. Do the batches in order X, Y, Z, AA; if you run out of room, stop after a picture and carry on when told "continue".
